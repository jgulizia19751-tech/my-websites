# Omaha Mobile Maintenance Website

A static, Netlify-ready website for Omaha Mobile Maintenance LLC.

## Files
- `index.html` — website content
- `styles.css` — responsive styling
- `logo.png` — supplied business logo
- `netlify.toml` — Netlify configuration

## Deploy to Netlify
1. Sign in to Netlify.
2. Choose **Add new project / Import an existing project** if using a Git repository, or use Netlify's manual drag-and-drop deploy.
3. Upload the contents of this folder (or the ZIP).
4. The site publishes with no build command required.
